## 3. Expected result
Every item of both packages `ported`, `excluded` through a closed reason, or left `missing` with a one-line reason in
REPORT.md. Upstream semantics exactly (wake-ups, change flags, events on removal). Guidance:
- **Exclusion patterns (closed reasons only):** thread-pool items (`thread_pool`, `num_threads`, …) are `SIMD/parallel`;
  `deformable` / `SoftElasticConstraint` are `soft bodies`; `voxelized_mesh` is `trimesh/voxels/3D heightfield`;
  `capsule_z` is `dim3-only`. Tighten the patterns so that nothing else moves; list every item that changed status.
- **No mutable references in Cairo:** `*_mut` accessors map to the existing copy-out / write-back pair (`collider` /
  `set_collider`) through `METHOD_RENAMES` only where the semantics match; say which.
- **Collider:** `compute_collision_aabb` (prediction distance), `compute_broad_phase_aabb`, `compute_swept_aabb`,
  `copy_from`, `Into<Collider>` for the builder; builder `position_wrt_parent`/`delta`, `default_density`,
  `default_friction`, `convex_hull` (2D hull of a point set, exact in Fixed, deterministic order; reject degenerate input
  as upstream returns `None`). `convex_decomposition*` / `convex_mesh` stay `missing` (lot SH2) unless trivial.
- **Sets and handles:** `ColliderHandle` / `ColliderPair` (`new`, `swap`, `zero`, `Default`), `ColliderSet`
  `invalid_handle`, `iter_enabled`, `set_parent` (re-parenting: upstream's position and mass-property updates),
  `take_modified` / `take_removed` if the pipeline has the equivalent state (otherwise `missing` + reason),
  `with_capacity` (no-op capacity is fine, say so); `RigidBody::colliders`,
  `recompute_mass_properties_from_colliders`.
- **World facade:** `pub type PhysicsWorld = World` if the script counts it; `active_bodies` / `num_active_bodies`
  (the game measures awake bodies per tick: derive them from the existing sleep state, **no new per-step
  bookkeeping**), `wake_up_all`, `rigid_bodies` / `all_colliders` (copy-out arrays in handle order), `Default` impls;
  `CollisionPipeline::step` (broad + narrow phase and events without the solver) only by reusing the existing stages.
  `Quarantine` (non-finite state cannot occur in Q32.32: overflow panics) and `PersistentIslands` internals stay
  `missing` with that reason unless the Cairo sleep code has a real equivalent; `BroadPhaseBvh`: Cairo's broad phase
  is not a BVH (ADR 0001) — map only what has the same contract.
