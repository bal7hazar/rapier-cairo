Work package: C3 — scalar-only body and collider components in `rapier_core`
Goal: port the pieces of Rapier's rigid-body and collider components that involve no vector type (only `fixed::Fixed`, integers, enums and flags), so that the geometry and dynamics crates can build on them the moment glam.cairo's `Vec2` lands. This is the dimension-agnostic, vector-free slice of upstream's `dynamics/rigid_body_components.rs` and `geometry/collider_components.rs`.

Files owned:
- `crates/rapier_core/src/rigid_body.cairo` (new) and submodules under `crates/rapier_core/src/rigid_body/`
- `crates/rapier_core/src/collider.cairo` (new) and submodules under `crates/rapier_core/src/collider/`
- `crates/rapier_core/src/lib.cairo` — only to add `pub mod` lines and re-exports
Do not touch any `Scarb.toml`, other crates, or the existing modules of `rapier_core` (`data`, `interaction_groups`, `integration_parameters`) except to *use* them.

Frozen interfaces: `fixed::{Fixed, FixedTrait, ZERO, ONE, MAX, …}`, `fixed::wide::*`; `rapier_core::interaction_groups::{Group, InteractionGroups, InteractionTestMode}`; `rapier_core::integration_parameters::IntegrationParameters` (for `dt`/`length_unit` when a computation needs them). Semantics: `*` floors, `/` truncates toward zero, overflow panics.

Upstream reference (read-only clone at /private/tmp/claude-501/-Users-bal7hazar-git-rapier-cairo--claude-worktrees-rapier-physics-cairo-benchmark-2d3317/239b7c62-97d7-47ea-9d79-74f81363555f/scratchpad/refs/rapier/src/): `dynamics/rigid_body_components.rs` (`RigidBodyType`, `RigidBodyChanges`, `RigidBodyDamping`, `RigidBodyDominance`, `RigidBodyActivation`, `RigidBodyAdditionalMassProps` — only its scalar parts), `dynamics/coefficient_combine_rule.rs` or wherever `CoefficientCombineRule` lives (grep it), `geometry/collider_components.rs` (`ColliderType`, `ColliderChanges`, `ColliderFlags`, `ColliderMaterial`, `ActiveCollisionTypes`, `ActiveHooks`, `ActiveEvents`), `pipeline/event_handler.rs` (`CollisionEventFlags`). Read `docs/PLAN.md` for what is cut (CCD, hooks as `dyn`, soft bodies…): keep flags as plain data even when the feature is cut, so defaults match upstream.

Requirements:
1. `rigid_body::{RigidBodyType, RigidBodyDamping, RigidBodyDominance, RigidBodyActivation}` with upstream defaults, `is_dynamic`, `is_fixed`, `is_kinematic`, `is_dynamic_or_kinematic`, `effective_group` (dominance), activation helpers (`new_active`, `cant_sleep`, `sleep`, `wake_up`, the time-accumulation update taking `dt` — port the exact comparison logic including "negative threshold never sleeps"), and the damping factor `1 / (1 + dt·d)` used by the velocity integration (`RigidBodyDamping::apply` or whatever upstream names it — verify the formula in `integrate`/`apply_damping` of the current upstream and mirror it; document the rounding).
2. `collider::{ColliderType, ColliderMaterial, CoefficientCombineRule, ActiveCollisionTypes, ActiveEvents, ActiveHooks, ColliderFlags}` with upstream defaults; `CoefficientCombineRule::combine(rule, a, b)` for friction/restitution with upstream's `Average / Min / Multiply / Max` semantics and the "max of the two rules wins" resolution; `ActiveCollisionTypes::test(type1, type2)` with upstream's bit semantics.
3. Bitflag types (`ColliderFlags`, `ActiveEvents`, `ActiveCollisionTypes`, `RigidBodyChanges`, `ColliderChanges`): implement as `u32`/`u16` newtypes with `contains`/`insert`/`remove`/`intersects`. Follow the ranking established in `interaction_groups` (bitwise `&` won there) but re-measure here for `contains` and `insert`, and also measure an arithmetic-only variant for `insert` (`x + bit·(1 - already_set)`); keep losers under `mod alternatives`.
4. Everything `#[derive(Copy, Drop, Serde, PartialEq, Debug)]`, `Default` where upstream has one, `///` docs with defaults and units, `errors` module for panics.
5. Tests: `test_*` for every default, every combine rule (including mixed rules), activation state machine (wake/sleep/timer accumulation across several `dt`, negative threshold), damping factor values at `dt = 1/60` for `d = 0, 0.5, 1, 100` (compute the expected raw values from the formula and comment them), `ActiveCollisionTypes` truth table; `gas_*` probes for `combine` (all four rules), `ActiveCollisionTypes::test`, flag ops (each candidate), `damping_factor`, activation update; inputs via `rapier_testing::opaque`, one `gas_baseline` per test module.

Acceptance: from the repo root, `scarb fmt --check --workspace`, `scarb lint --workspace --deny-warnings`, `scarb build --workspace`, `snforge test --workspace` all pass; `python3 scripts/gas.py diff` table in the report with the flag-op candidate ranking.

Out of scope: anything holding a vector or pose (positions, velocities, mass properties, forces), shapes, the arena of bodies/colliders, `Scarb.toml` files, CI.
