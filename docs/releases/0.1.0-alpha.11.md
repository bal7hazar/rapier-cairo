# Release record: 0.1.0-alpha.11

Record of what was published on scarbs.xyz as `0.1.0-alpha.11`, and how.

## The release commit

- Release commit: `1c79832dd92aa2238bc0e9754e0cd0a4381f3bd4`, on the branch `release/0.1.0-alpha.11` (kept, never
  merged), cut from `7c3c8c869672176cd0e4dda0bbdf097198731bb1`, the merge of the release pull request #280.
- Its whole diff removes the `[dev-dependencies]` of the six published crates. Their test helpers, `rapier_testing` and
  `rapier_golden`, are not published, so the manifests on `main` could not be packaged. `main` keeps the
  dev-dependencies (`slingfall/OPERATIONS.md` §7, the project manager's ruling with the Overseer of 2026-10-03).
- The release commit was landed by fast-forward (#281, review PASS, Opus), never squash-merged, so the commit that was
  packaged is the commit on the branch.
- CI: every job that does not need the removed dev-dependencies is green on `1c79832`; the test jobs and both sinks are
  green on `7c3c8c8` on `main` (run 37299536942).

## How it was published

- Five staged goes of the project manager, with the same commands as alpha.10: each crate verifies against its
  predecessors on the registry only after they are published, so a crate was packaged and published once the previous
  one was on the registry.
- Tag `v0.1.0-alpha.11` on `1c79832` (annotated), and the GitHub release (pre-release):
  `https://github.com/bal7hazar/rapier-cairo/releases/tag/v0.1.0-alpha.11`.

## Upgrading from 0.1.0-alpha.10

- Dependencies: rapier-cairo now depends on `fixed` 0.5.0 and `glam_core` 0.5.0 (DEP5, #279). A consumer that uses
  `Fixed` or `Vec2` itself must move to `fixed` 0.5 and `glam_core` 0.5 too, or it compiles two generations of the same
  types.
- One source break (PX9, #275): `GenericJointBuilder` gained a crate-private field, so a struct literal
  `GenericJointBuilder { data }` written outside the crate no longer compiles. Use `GenericJointBuilderTrait::new`.
- Results: unchanged. No step result, no `WorldState` format and no class hash moves.
